│     Rationale: Device/user state must survive rebuilds                     │
│     Solution: Skip devices, device_users, roles in drop list               │
│                                                                             │
│  3. LOOKUP DATA PHILOSOPHY                                                  │
│     Rationale: Seed only essential, version-controlled config data         │
│     Solution: Roles + Warehouse + Chart of Accounts (not customers)        │
│                                                                             │
│  4. ERROR HANDLING PHILOSOPHY                                               │
│     Rationale: Critical ops must abort, idempotent ops can continue        │
│     Solution: seedLookupTables returns error, dropAllTables logs warnings  │
