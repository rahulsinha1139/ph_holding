[1] FLEXIBLE COLUMN DETECTION

[2] SMART CUSTOMER MATCHING
    ▸ Exact match: "ALBA" → ALBA customer record
    ▸ Normalized match: "aluminium bahrain b.s.c.(c)" → ALBA
    ▸ Partial match: "BAPCO Refining" → BAPCO
    ▸ Fallback: Logs warning, skips row (doesn't crash)

[3] BAHRAIN VAT CALCULATION (10%)
    ╔═══════════════════════════════════════╗
    ║ Total = Subtotal × 1.1                ║
    ║ Subtotal = Total ÷ 1.1                ║
    ║ VAT = Total - Subtotal                ║
    ╚═══════════════════════════════════════╝

    Example:
    Total (from Excel):  BHD 1,100.000
    Subtotal:            BHD 1,000.000
    VAT (10%):           BHD   100.000

[4] FLEXIBLE DATE PARSING (14 FORMATS)
    ✓ DD/MM/YYYY (Bahrain/UK)   → "15/06/2025"
    ✓ MM/DD/YYYY (US)           → "06/15/2025"
    ✓ YYYY-MM-DD (ISO)          → "2025-06-15"
    ✓ DD-Mon-YYYY               → "15-Jun-2025"
    ✓ Excel serial dates        → 45825 → 2025-06-15
    ✓ ...and 9 more variants

[5] AUTO INVOICE NUMBER GENERATION
    If missing:  INV-2025-0001, INV-2025-0002, ...
    If present:  Uses original Tally invoice number

[6] PAYMENT STATUS HEURISTICS
    IF invoice_age > 90 days:
        Status = "Sent", PaymentStatus = "Paid"
        AmountPaid = NetAmount, AmountDue = 0
    ELSE:
        Status = "Sent", PaymentStatus = "Unpaid"
        AmountPaid = 0, AmountDue = NetAmount
