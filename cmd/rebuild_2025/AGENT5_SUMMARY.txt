   - Maps raw Excel status to (Stage, Status) tuple
   - Handles: Won, Lost, Proposal, Negotiation, Lead, Pending

   - Returns probability 0.0-1.0 based on stage
   - Lead=10%, Qualified=25%, Proposal=50%, Negotiation=75%, Won=100%, Lost=0%

   - Handles 10+ date formats

🎓 KEY DESIGN DECISIONS

1. Reused parseFlexibleDate() from invoices.go
   - Avoided code duplication
   - Signature: func(string) time.Time (not (time.Time, error))

2. Customer normalization via master_data.go
   - Leverages existing 67-variant map
   - Ensures consistency with customer master data

3. Placeholder UUIDs for unmatched customers
   - Allows import to complete
   - Logs warnings for manual review
   - Better than hard failure

4. Batch insertion (100/batch)
   - Reduces DB round-trips
   - Continues on partial failures
   - Logs progress for monitoring

5. Comprehensive column detection
   - 8 field types, 30+ aliases
   - Flexible enough for real-world Excel variations
   - Fails gracefully when columns missing
